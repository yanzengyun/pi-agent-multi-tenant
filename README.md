# Pi Assistant · 把一台服务器变成多人可用的微信 AI 助手

**管理员部署一次，朋友扫码即用；每个人都有自己的会话、记忆、人物设定、笔记和工作目录。**

它不是只有一层聊天页面的 Demo，而是一套可以真正交给朋友使用的自托管个人助手底座：管理员发出邀请，用户注册后用自己的微信扫码连接，此后直接在熟悉的聊天窗口里交流、记笔记、搜索资料、设置提醒或处理文件。模型和基础设施共享，私人状态按用户隔离，不需要为每个人常驻一整套 Pi 进程。

## 为什么值得部署

- **用户几乎没有学习成本**：不用安装新 App，也不用接触模型配置；注册、扫码，然后在微信里说话。
- **笔记不是聊天附件**：人与自己的助手共用一份可浏览、可编辑、可检索的 SilverBullet 知识空间，聊天成果能长期沉淀。
- **多用户不是复制五套服务**：一个后端按需创建独立 AgentSession，共享模型、笔记服务和沙箱池，降低小规模部署成本。
- **隔离做到工具边界里**：会话、记忆、笔记、工作目录和微信绑定均按服务端身份路由，不能靠提示词切换成其他用户。
- **管理员真正能运维**：邀请、账号、连接、提醒、配额错误和运行记录集中管理；生产数据可以备份、迁移和恢复。
- **保留 Pi 的扩展能力**：继续使用 Pi 原生上下文与工具循环，并按需接入搜索、语音、命令沙箱和新的业务工具。

适合希望给家人朋友提供私人 AI、为小团队搭建内部助手，或研究 Pi Agent 多租户 Harness 的开发者。当前定位是少量受邀用户的可运行系统，不宣称已经具备大规模 SaaS 的并发和租户治理能力。

## 项目亮点

| 能力 | 使用方式 |
| --- | --- |
| **微信扫码接入** | 点击连接、微信扫码确认，再发一条消息开始聊天。支持用户自行绑定，也支持管理员代为展示二维码。 |
| **人与助手共享笔记** | 微信里列出、搜索和整理自己的 SilverBullet 笔记，用户在浏览器继续编辑同一份内容；各用户空间独立。 |
| **多租户管理** | 一个后台管理邀请、用户、微信连接、提醒和运行记录；各用户的聊天、记忆、笔记与工作文件独立保存。 |
| **可定制的朋友型助手** | 默认自然聊天，适时建议和总结。人物设定可在个人页面编辑、让 AI 起草，或直接在微信中修改。 |
| **持久记忆与会话** | 跨对话保留用户偏好和会话记录，不需要为每个用户启动一套常驻 Pi 进程。 |
| **详细运行记录** | 管理员可以查看每次注入的提示词与记忆、工具调用、结果和错误，便于排查问题。 |
| **独立工作目录** | 可选离线命令沙箱，运行 Bash/Python、保存脚本和文件；用户工作目录跨命令和服务重启保留。 |
| **搜索、提醒与语音** | 可选 MiniMax 网页搜索、一次性/每日/周一至周五文本提醒；每个人可选择音色、语速、语气，并试听或配置每次附带 MP3 回复。 |

共享笔记指**用户与自己的助手共用一份笔记**。SilverBullet 服务共用，每个用户有独立 Space 和访问权限。

## 从邀请到微信聊天

1. 管理员生成邀请链接，分享给用户。
2. 用户设置账号和密码，注册后自动进入个人页面。
3. 用户点击“扫码连接微信”，用自己的微信扫码并确认。
4. 在微信发一条消息，开始使用助手；个人页面继续用于管理连接、笔记、人物设定和密码。

邀请链接默认 **7 天有效、仅可使用一次**。用户只需自己的登录信息；管理员也可以为已有账号生成激活邀请。

## 可以对助手说什么

```text
帮我把今天讨论的旅行计划整理成笔记并保存。
我有哪些笔记？帮我找之前关于游泳的记录。
在刚才那篇笔记里补充预算，保留原来的内容。
删除“旅行计划”这篇笔记，先归档。
把刚才归档的笔记恢复回来。
永久删除“测试草稿”这篇笔记，我确认。
我的笔记网址是什么？用什么账号登录？
我的个人页面在哪？你能帮我做什么？
记住我喜欢简短的中文回答。
再记一条：我正在学习Python。
把学习Python改成学习Rust，其他记忆保留。
明天下午三点提醒我带资料。
搜索一下这个问题最近有哪些公开资料。
在我的工作目录写一个 Python 脚本，处理这份数据。
请用语音回复一段简短的总结。
把我的语速改成0.75倍，语气平静一点。
/voice 你好，今天也要开心。
```

长期记忆默认追加，支持按条目修正和遗忘；完整替换需要明确要求。机制、容量和工具参数见[记忆说明](docs/memory.md)。

工具按部署配置启用。笔记在用户明确要求时保存；更新已有页面先读取并使用 ETag，避免覆盖其他修改；写入成功后才确认。助手通过只读 `account_info` 查询当前用户的真实入口和可用功能。

笔记删除默认移入自己 Space 的 `归档/YYYY-MM/<唯一编号>/原路径.md`，保留正文和可恢复路径；同名归档不覆盖。恢复时原位置已有页面则拒绝覆盖。明确要求永久删除时才移除当前文件，历史备份可能保留。操作使用读取到的 ETag 防止误删新版本，审计按用户隔离，只记元数据。当前仅支持单篇 Markdown，不提供管理台批量清理。

笔记列表提供标题、修改时间、链接和分页；正文检索使用 `rg`，无需浏览器或向量库。默认隐藏系统页及归档，结果返回原文片段；扫描或结果不完整时会明确标记。参数与部署依赖见[笔记列表与搜索](docs/note-search.md)。

模型服务明确返回额度耗尽时，系统会直接在微信回复固定提醒，无需模型生成；不会把普通限流误报为额度用完。每条失败请求的提醒沿用持久 outbox 和去重 client ID，发送失败后重试。

## 架构

```mermaid
flowchart LR
  Admin[管理员后台] --> API[共享 Node.js 后端]
  Account[邀请与个人页面] --> API
  WeChat[用户各自的微信连接] --> API
  API --> Queue[SQLite 持久化队列]
  Queue --> Pi[Pi SDK / 按用户独立会话]
  Pi --> Memory[各自的记忆与人物设定]
  Pi --> Notes[SilverBullet / 各自 Space]
  Pi --> Sandbox[可选命令沙箱 / 各自持久目录]
  Pi --> Tools[搜索 / 提醒 / MP3]
  API --> Trace[按用户保存的运行记录]
```

- **一个共享后端**：Pi SDK 按需创建用户自己的 AgentSession，结束后释放。当前模型任务全局串行执行。
- **Pi 原生提示与注入**：保留默认 system 构造，人物设定通过用户自己的 AGENTS.md 项目上下文进入，SQLite 长期记忆由扩展注入稳定快照；工具按账号授权提供。
- **用户之间隔离**：身份由服务端登录状态或微信绑定确定，模型不能通过提供 `userId` 切换到其他用户。
- **基础设施共用**：SQLite、SilverBullet 和命令执行服务集中部署，记忆、会话、笔记权限与持久目录按用户划分。
- **权限保持有限**：命令只在离线沙箱执行；用户人物设定不能开启宿主机权限、增加工具或访问其他用户。

服务端与主机管理员仍能读取运行数据；运行记录也可能包含私人内容。这里的隔离保护不同用户之间的访问。

## 快速体验

需要 **Node.js ≥ 22.19**。先启动不调用真实模型、不连接微信的本地演示模式：

```sh
git clone https://github.com/yanzengyun/pi-agent-multi-tenant.git
cd pi-agent-multi-tenant
npm ci --omit=peer --ignore-scripts --no-audit --no-fund
cp .env.example .env
```

在 `.env` 中设置自己的管理员密码，至少 12 位：

```dotenv
ASSISTANT_ADMIN_PASSWORD=replace-with-your-own-long-password
```

启动：

```sh
node --env-file=.env src/main.mjs
```

打开 `http://127.0.0.1:32214/`，管理员账号为 `admin`。密码只在首次初始化数据库时使用；修改环境变量不会重置已有管理员密码。

演示模式可以体验管理后台、邀请注册、个人页面和人物设定。要接入真实模型、微信和笔记，请继续阅读 [部署指南](docs/deployment.md)。

## 接入真实助手

安装锁定的 Pi SDK：

```sh
npm run setup:pi
```

在私有 `.env` 中配置：

```dotenv
ASSISTANT_ENGINE=pi
ASSISTANT_MODELS_FILE=./models.json
MINIMAX_CN_API_KEY=your-private-api-key
ASSISTANT_WECHAT=on
ASSISTANT_SEARCH=on
ASSISTANT_TTS=on
```

聊天模型支持 MiniMax 和 DeepSeek，搜索和语音使用 MiniMax；每个用户共用服务端提供的密钥。DeepSeek 切换方法见[部署指南](docs/deployment.md)。公网使用需配置 HTTPS、固定 Origin 和安全 Cookie。笔记需要独立配置 SilverBullet，命令工具需要单独安装沙箱执行服务。

## 当前边界与后续方向

- 用户在微信聊天，网页负责账号与配置；当前没有网页聊天窗口。
- 语音回复是 **MP3 附件**，当前没有可用的原生微信语音气泡。
- 提醒支持一次性、每日和周一至周五（北京时间，不含节假日调休）文本投递；超过原定时间30分钟不再补发，发送失败有退避与错误记录。定时模型复盘与复杂周期尚未实现。
- 命令沙箱默认预建 6 个持久工作区，每个约 100MiB 可用；名额可扩容，并非注册用户总数限制。单次执行最多 30 秒、192MiB 内存，直接联网关闭。
- 目前适合从少量受邀用户开始；并发、容量、长期重连与资源配额需按实际负载验证。
- 后续方向：通用一键部署、用户计量与配额、更多模型和工具适配。
